# SmartEdu AI 🎓☁️

## Cloud-Based Student Performance Prediction & Early Intervention System

SmartEdu AI is a Machine Learning and Cloud-based system designed to predict student academic performance, identify students who are at academic risk, explain the major factors affecting their performance, and provide personalized recommendations for improvement.

## 🚀 Key Features

- 📊 Student Performance Prediction
- ⚠️ Academic Risk Detection
- 🔔 Early Warning System
- 🤖 Machine Learning-based Prediction
- 🔍 Explainable AI
- 💡 Personalized Recommendations
- 🎯 What-If Performance Simulator
- 👨‍🎓 Student Dashboard
- 👨‍🏫 Teacher Dashboard
- 👨‍💼 Admin Dashboard
- ☁️ Cloud-based Data Storage

## 🧠 Machine Learning

The system uses student-related academic features such as:

- Attendance Percentage
- Previous Examination Marks
- Assignment Scores
- Internal Assessment Marks
- Study Hours
- Previous GPA
- Class Participation
- Number of Backlogs

The ML model predicts the student's expected performance and classifies the student into:

- 🟢 Low Risk
- 🟡 Medium Risk
- 🔴 High Risk

## ⭐ Unique Features

### 1. Early Warning System

The system identifies students who may be at academic risk before their final examination.

### 2. Explainable Prediction

Instead of only showing the prediction, the system explains the major factors affecting the student's result.

Example:

Attendance        → 35%
Previous Marks    → 28%
Assignments       → 20%
Study Hours       → 17%

### 3. What-If Simulator

Students can check how their predicted performance may change if they improve factors such as attendance or study hours.

Example:

Current Prediction: 58%

Improved Attendance + Study Hours

New Prediction: 71%

### 4. Personalized Recommendations

The system provides suggestions based on the student's weaknesses.

Example:

- Improve attendance
- Complete pending assignments
- Increase daily study time
- Practice weak subjects
- Take regular mock tests
